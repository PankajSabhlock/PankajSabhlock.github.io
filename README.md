# Pankaj Sabhlock - Personal Website

A responsive portfolio covering Artificial Intelligence, data strategy, responsible governance, professional recognition and leadership.

## GitHub Pages

The complete live website is at the repository root. A single HTML file is not required. Keep `index.html`, `styles.css`, `site.js`, the photographs and the `assets/` folder together.

To publish, open **Settings > Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then click **Save**. The `.nojekyll` file lets GitHub serve the static files directly.

Repository intended for this website: **PankajSabhlock/PankajSabhlock.github.io**. The live address will be confirmed after GitHub Pages finishes its deployment.

## Files and versions

- `index.html`: content and navigation.
- `styles.css`: responsive styling, transitions and 3D icon presentation.
- `site.js`: stories, filters, sticky titles and motion controls.
- `portrait.png`, `award-photo.jpg`, `assets/`: website images and icon licence.
- `Current-Version_2026-10-05/`: an explicit copy of this release.
- `Obsolete/`: reserved for superseded releases.

Animations respect reduced-motion settings and can be paused. Contact buttons open email or LinkedIn; this site has no form submission service or server-side runtime.
